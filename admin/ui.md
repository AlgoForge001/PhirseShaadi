# Phirse Shaadi – New Brand Theme Update Guide

## Objective
Update the complete UI/UX color system of the Matrimony App according to the new **Phirse Shaadi** logo and branding.

The app should feel:
- Premium
- Emotional
- Trustworthy
- Modern
- Elegant
- AI-powered
- Warm and welcoming

Avoid dark cyber themes or overly colorful gradients.

---

# Brand Identity

## Brand Name
Phirse Shaadi

## Brand Personality
- Elegant
- Romantic
- Trustworthy
- Soft Premium
- Emotional Connection
- Modern AI Matchmaking

---

- Primary buttons

- Active states
- Highlights

```css

* Headers

* Hero section
* CTA buttons
* AI Match cards

```

Use in:

* Background overlays
* Card glow

```css

```

# UI Style Direction

## Buttons

Style:

* Rounded corners
* Soft shadow
* Elegant hover animation

Primary Button:

* Background: Primary Pink Gradient
* Text: White

Secondary Button:

* White background
* Pink border
* Pink text

---

# Typography

## Font Style

Use modern elegant fonts like:

* Poppins
* Nunito
* DM Sans

Avoid:

* Tech fonts
* Sharp futuristic fonts

---

# Card Design

Cards should:

* Have soft shadows
* Use rounded corners (16px–24px)
* Use white/light blush background
* Minimal borders

Example:

```css
box-shadow: 0 10px 30px rgba(216, 27, 96, 0.08);
border-radius: 20px;
```

---

# App Background Style

Avoid plain white everywhere.

Use:

* Soft blush gradients
* Light romantic glow
* Very subtle heart/pattern decorations

Background Feel:

* Warm
* Premium
* Clean

---

# Icon Style

Icons should:

* Use pink + gold combination
* Be minimal
* Rounded style
* Elegant line icons preferred

Avoid:

* Heavy neon icons
* Harsh sharp icon packs

---

# AI Feature UI Theme

AI sections should feel:

* Smart but emotional
* Elegant technology
* Human-centered AI

Use:

* Glassmorphism cards
* Soft gradients
* Glow effects
* Floating UI elements

---

# Animation Style

Use subtle animations:

* Smooth hover scaling
* Fade-in transitions
* Floating cards
* Soft glow pulse

Avoid:

* Aggressive animations
* Fast transitions
* Gaming-style motion

---
